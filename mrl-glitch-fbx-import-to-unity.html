Step by step: new Unity project (Quest 3) + import FBX/WAV

0) Pre-check (1 minute)

  • Confirm in Unity Hub that you have a Unity LTS installed (e.g.: 2022.3 LTS) with Android Build Support (SDK/NDK/OpenJDK).
  • Quest 3 in Developer Mode and connected to MQDH (for Build & Run later).

1) Create the project from scratch

  1. Open Unity Hub → New Project
  2. Template: 3D SRP.
  3. Suggested name: MRL_Glitch_FBX_Import
  4. Location: a dedicated folder just for this project (Documents/Unity/MetaQuest3).
  5. Create.

Practical tip: as soon as the project opens, create a folder structure under Assets/ like this:

  • Scenes
  • FBX
  • Audio
  • Scripts

2) Check if the FBX actually has animation

For each FBX (01..., 02..., etc.):

  1. Click the FBX in the Project window.
  2. In the Inspector → Animation:
    • Import Animations: ON
    • Check if there is any clip listed (name of the take/clip).
  3. If no clip appears, this FBX may be just a “static mesh” (or the animation was exported into another file).

3) Create a clean test scene + play 1 FBX in the Editor

Goal: confirm the imported FBX actually animates inside Unity (Editor) before going to Quest.

  1. Create a new scene (SRP)
  • File → New Scene…
  • Select Basic (URP)
  • Click Create
  1. Save the scene
  • File → Save As…
  • Save to: Assets/Scenes/
  • Name: 00_SmokeTest_FBX.unity
  1. Drop one FBX into the scene
  • In the Project window, open Assets/FBX/
  • Drag only 01_Razor_...Sequence.FBX into the Hierarchy (or directly into the Scene view)
  1. Try the simplest playback
  • Press Play
  • If the animation runs automatically → ✅ Step 3 done.
  1. If it does NOT animate automatically (common) → force playback with an Animator
  • Create an Animator Controller:
    • Project window → Right click → Create → Animation → Animator Controller
    • Name: AC_SEQ01_Razor
  • Select the FBX object in the Hierarchy
    • Add Component → Animator
    • Drag AC_SEQ01_Razor into the Animator Controller field
  • Open the Animator window:
    • Window → Animation → Animator
  • In the Project window, expand the FBX (small triangle) to reveal its sub-assets
    • Find the clip (often called Unreal Take)
    • Drag the clip into the Animator graph (it becomes the default state)
  • Press Play again → animation should run ✅

Why “if it doesn’t animate automatically” is quite common
It’s very common to import an FBX that does contain an animation clip, drop the model into the scene, press Play… and see nothing moving. Unity often imports the clip as a sub-asset of the FBX, but does not automatically:

  • create an Animator Controller, or
  • assign that controller to the GameObject, or
  • set the imported clip as the default state.
    So the animation exists, but nothing is telling Unity to play it.
    In those cases, you need to manually create an Animator Controller, assign it to the object, and add the imported clip as the default state in the Animator.
